# analytics-portfolio
SQL, Python, R projects demonstrating data analysis, machine learning, and statistical modeling skills for analytics roles


## Rental Market Analysis (R Project)

**Files:**
- `rental_market_analysis.Rmd` - Full R analysis pipeline (data loading, cleaning, modeling)
- `rental_cleaned_data.csv` - Output dataset (106,521 renter households)

**Analysis:**
- Loaded raw IPUMS Census data and performed data cleaning and transformation
- Built fixed effects regression models to analyze housing price drivers
- Key finding: $10K income increase correlates with 1.77% rent increase
- Tools: R (dplyr, fixest, ggplot2)

## SQL Data Extraction (SQL Project)

**Files:**

`rental_analysis_queries.sql` - Four SQL queries for rental data analysis
`sql_query_results.txt` - Query output showing data extraction results

**Queries:**

Rent variation by education and employment status
Rent by housing characteristics (bedrooms, structure type)
Year-over-year rent trends by geography
